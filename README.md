# Group Sharer — Bot + Userbot

একটি Telegram বট যা আপনার নিজের অ্যাকাউন্ট (Userbot) ব্যবহার করে সিলেক্ট করা প্রাইভেট গ্রুপগুলোতে লিংক/টেক্সট শেয়ার করে।

## ফিচার
- 🔑 **লগইন**: `/login` → ফোন → OTP → (2FA পাসওয়ার্ড) → সেশন সেভ (আর লগইন লাগে না)
- 📋 **গ্রুপ ম্যানেজমেন্ট**: `/addgroup`, `/removegroup`, `/cleargroups`, `/groups`
- 📤 **শেয়ার**: যেকোনো লিংক/টেক্সট পাঠালেই সব সিলেক্ট করা গ্রুপে চলে যায়
- 🤖 **অটো-পোস্ট সিস্টেম**: একটি মেসেজ সেট করে দিলে সেটা নিয়মিত (১-২ ঘণ্টা পর পর) সব গ্রুপে অটো পোস্ট হবে
- 📊 **রিপোর্ট**: প্রতিটি গ্রুপে পাঠানো হয়েছে/নहीं এবং কেন (FLOOD_WAIT, পারমিশন, ব্যান ইত্যাদি)
- 🛡️ **নিরাপত্তা**: শুধু Owner ID ব্যবহার করতে পারে
- ⏱️ **স্মার্ট ডিলে**: গ্রুপ প্রতি র‍্যান্ডম ২০–৬০ সেকেন্ড (FLOOD_WAIT এড়াতে)

## 🤖 অটো-পোস্ট সিস্টেম (নতুন)

একটি মেসেজ সেট করে দিলে বট সেটা **নিয়মিত সব গ্রুপে অটো পোস্ট** করবে — আপনাকে আর কিছু করতে হবে না।

### কীভাবে কাজ করে
1. `/setMsg` দিন → বট বলবে "মেসেজটি পাঠান"
2. মেসেজটি পাঠিয়ে দিন → সেভ হয়ে যাবে
3. `/autostart` দিন → অটো-পোস্ট চালু

### পোস্ট কীভাবে হয় (ট্রাকিং এড়ানোর জন্য)
- প্রতিটি গ্রুপে **২০-৬০ সেকেন্ড** র‍্যান্ডম বিরতিতে ধীরে ধীরে পাঠানো হয়
- পাঠানোর ঠিক আগে গ্রুপে `typing...` দেখানো হয় (মানুষের মতো দেখায়)
- পুরো রাউন্ড শেষ হলে **১-২ ঘণ্টার মধ্যে একটি র‍্যান্ডম সময়** বেছে নিয়ে আবার পোস্ট শুরু হয়
- বট বন্ধ/রিস্টার্ট হলেও সেটেড মেসেজ মনে থাকে (DB-তে সেভ)

### কমান্ড
| কমান্ড | কাজ |
|--------|-----|
| `/setMsg` | অটো-পোস্টের মেসেজ সেট করুন (তারপর মেসেজ পাঠান) |
| `/autostart` | অটো-পোস্ট চালু করুন |
| `/autostop` | অটো-পোস্ট বন্ধ করুন (মাঝপথে থাকলেও থামবে) |
| `/astatus` | অটো-পোস্ট স্ট্যাটাস ও পরবর্তী পোস্টের সময় দেখুন |
| `/autoinfo` | অটো-পোস্ট সিস্টেম সম্পর্কে বিস্তারিত |

> 💡 মেনু বাটনে (`/menu`) "🤖 অটো-পোস্ট" বাটনও আছে — সেখান থেকেও সব কাজ করা যায়।

## WebUI (অ্যাডমিন প্যানেল)

ব্রাউজার থেকে গ্রুপ, শেয়ার লগ, অটো-পোস্ট ও সেটিংস ম্যানেজ করার জন্য আলাদা Flask প্যানেল আছে।
এটি বটের একই `data.db` পড়ে, কিন্তু বট প্রসেসকে স্পর্শ করে না।

```bash
chmod +x run_webui.sh
./run_webui.sh          # অথবা: python3.8 webui.py
```

- ঠিকানা: **http://127.0.0.1:8017** (শুধু localhost; বাইরে এক্সপোজ করতে SSH tunnel ব্যবহার করুন)
- প্রথমবার খুললে `/setup` পেজে একটি পাসওয়ার্ড সেট করতে হবে
  (scrypt হ্যাশ হিসেবে `settings` টেবিলের `user_id=0`, key `webui_password_hash`-এ সেভ হয়)
- পেজগুলো: **Dashboard**, **Groups** (user filter / search / single add / bulk add / delete / CSV-JSON import-export),
  **Share Log** (status, group, user, date filter + pagination), **Auto Log**, **Settings**
- নতুন multi-user DB-তে অটো সেটিংস (`auto_msg`, `auto_min_hour`, `auto_max_hour`, `auto_enabled`)
  প্রতি ইউজারের `user_state` টেবিলে থাকে; পুরোনো DB-তে সেগুলো `settings`-এ থাকে।
  Settings পেজে ইউজার সিলেক্ট করে সেই ইউজারের মান এডিট করা যায়; টোকেন/সেশন/হ্যাশ ঢাকা থাকে
- "Trigger share round now" বাটন আছে, কিন্তু বটে এখনো আলাদা manual trigger নেই —
  তাই এটি "not supported yet" মেসেজ দেখায়

> WebUI আলাদা প্রসেসে চলে, তাই বট চালু থাকা অবস্থাতেও নিরাপদে ব্যবহার করা যায়।

## সেটআপ
```bash
cd /root/agents/personal/workspace/group-sharer
chmod +x run.sh
python3 setup.py  # ইন্টারঅ্যাক্টিভ কনফিগারেশন
python3 bot.py    # বা ./run.sh
```

## কনফিগ (`config.json`)
```json
{
  "bot_token": "123456:ABC...",
  "api_id": 12345,
  "api_hash": "abcdef...",
  "owner_id": 123456789,
  "delay_min": 20,
  "delay_max": 60,
  "max_flood_wait": 300
}
```

- `bot_token`: @BotFather থেকে
- `api_id`, `api_hash`: https://my.telegram.org → API development tools
- `owner_id`: @userinfobot থেকে আপনার Telegram ID

## কমান্ডসমূহ
| কমান্ড | কাজ |
|--------|-----|
| `/start` | হেল্প মেনু |
| `/status` | লগইন/গ্রুপ স্ট্যাটাস |
| `/login` | ইউজারবট লগইন (ফোন → OTP → 2FA) |
| `/cancel` | বর্তমান অপারেশন বাতিল |
| `/groups` | সিলেক্ট করা গ্রুপ লিস্ট |
| `/addgroup <লিংক/আইডি>` | গ্রুপ যোগ (যেমন `https://t.me/...` বা `@username`) |
| `/checkgroups` | জয়েন করা সব গ্রুপ দেখুন — ✅ মানে অ্যাড করা, ➕ মানে এখনো বাকি |
| `/removegroup [নম্বর]` | গ্রুপ রিমুভ (নম্বর না দিলে বাটন দেখাবে) |
| `/cleargroups` | সব গ্রুপ মুছে ফেলা |
| `/logs` | সাম্প্রতিক ১০টি শেয়ার রিপোর্ট |

## শেয়ার কীভাবে করবেন
লগইন → গ্রুপ যোগ → **যেকোনো লিংক বা টেক্সট পাঠান** → বট কনফার্মেশন চাইবে → ✅ চাপলে সব গ্রুপে পাঠাবে → প্রতিটি গ্রুপের রিপোর্ট আসবে।

## নোট
- Userbot সেশন `userbot.session` ফাইলে সেভ থাকে (দ্বিতীয়বার লগইন লাগে না)
- প্রাইভেট গ্রুপে আপনার অ্যাকাউন্ট **আগে থেকে মেম্বার** হতে হবে
- FLOOD_WAIT এলে বট অটোমেটিক ওয়েট করে রিজিউম করবে
- ১৫+ গ্রুপ হলে পুরো শেয়ার করতে কয়েক মিনিট লাগতে পারে

## ফাইল স্ট্রাকচার
```
group-sharer/
├── config.json      # কনফিগারেশন
├── setup.py         # ইন্টারঅ্যাক্টিভ সেটআপ
├── run.sh           # রান স্ক্রিপ্ট
├── restart.py       # বট রিস্টার্ট (লগ সহ)
├── bot.py           # মূল বট (python-telegram-bot)
├── auto.py          # অটো-পোস্ট সিস্টেম (সেটিংস, র‍্যান্ডম ইন্টারভাল, ফরম্যাট)
├── engine.py        # ইউজারবট ইঞ্জিন (Telethon)
├── db.py            # SQLite ডাটাবেস
├── webui.py         # WebUI (Flask admin panel)
├── templates_webui/ # WebUI HTML টেমপ্লেট
├── static_webui/    # WebUI CSS
├── run_webui.sh     # WebUI স্টার্টার
├── test_auto.py     # অটো-পোস্ট লজিক টেস্ট
├── test_integration.py # শেয়ার ও scheduler ইন্টিগ্রেশন টেস্ট
├── test_checkgroups.py  # /checkgroups ✅/➕ মার্কিং টেস্ট
├── test_runtime.py      # চলমান বট প্রসেস ও লগ যাচাই
├── userbot.session  # টেলিগ্রাম সেশন (অটো-জেনারেট)
└── data.db          # SQLite ডিবি (অটো-জেনারেট)
```
